Oplus Network Modes bundles DexKit 2.3.0, copyright DexKit contributors.
DexKit code outside Core is distributed under Apache-2.0; its native Core is
distributed under LGPL-3.0. Their license texts are included in this directory.
Source for this exact version: https://github.com/LuckyPray/DexKit/tree/2.3.0
Native library: libdexkit.so (packaged as a separate shared library).

The APK also bundles Kotlin standard library and FlatBuffers, both distributed
under Apache-2.0. See their sources and notices:
https://github.com/JetBrains/kotlin
https://github.com/google/flatbuffers

DexKit's native LGPL-3.0 refers to the GNU GPL version 3; its text is at
